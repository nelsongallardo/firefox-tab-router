# Changelog

## 1.0.1

- Prepare the first public Firefox Add-ons listing.
- Same routing behavior and permissions as 1.0.0.

## 1.0.0

- Route HTTP(S) URLs to native Firefox tab groups with origin and path boundaries.
- Reuse existing groups, including a unique destination in another window.
- Local rule editor, ordered rules, pause control, and URL preview.
- Skip pinned/private tabs and avoid ambiguous cross-window routing.
- No runtime dependencies, telemetry, or extension network requests.
