How routing works

A rule matches the exact website and the path below it. For example, https://github.com/example/project includes that repository’s PRs and issues, but not project-other. Query strings and fragments on links are ignored. Rules do not use wildcards.

Group names are case-sensitive. An existing group in the tab’s window is preferred. Otherwise, a single matching group in another window receives the tab. If several other windows have that name, the tab stays put and the toolbar shows “?”. Give those groups distinct names to resolve this.

If no open group matches, one is created. Saved and closed groups are not reopened. Existing group colors are preserved; the selected color is used for new groups.

Saving applies to future tab openings and URL changes. Existing tabs are not swept into groups. Pinned and private tabs are skipped. Manual moves are respected until the next URL change. Browser session restoration may produce new-tab events.

Rules stay on this device. No tracking. No network requests.
